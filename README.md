# Challenge Loans

Mais um desafio resolvido! Este projeto implementa um sistema de empréstimos com um método de verificação baseado nas regras fornecidas no desafio. Desenvolvido em **Java** e **Spring Boot**.

## 🚀 Tecnologias Utilizadas

- **Java**: Linguagem principal do projeto.
- **Spring Boot**: Framework para criação da API.
- **JUnit**: Para testes automatizados das regras de negócio.

## ✨ Funcionalidades

- **Validação de Empréstimos**: Implementação das regras definidas no desafio.
- **Diferentes Tipos de Empréstimos**:
  - **Empréstimo Pessoal**: Disponível para clientes elegíveis.
  - **Empréstimo Consignado**: Disponível para clientes com renda mínima de R$5000,00.
  - **Empréstimo Garantido**: Sujeito a regras específicas.
- **Cálculo de Taxa de Juros**:
  - **Pessoal**: 4.0% ao mês.
  - **Consignado**: 2.0% ao mês.
  - **Garantido**: 3.0% ao mês.
